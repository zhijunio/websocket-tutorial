# Teaching Notes

- Code-oriented lessons may have one independent example project per lesson.
- Store example projects under `examples/`.
- Each example must be runnable independently and include its own build configuration and verification instructions.
- Code lessons should explain the key source flow, state invariants, and what tests prove; avoid line-by-line narration.
- Use diagrams or other images when they materially clarify a protocol flow, state model, or architecture boundary.
- Current baseline: Java 25, Spring Boot 4.1.1, Maven, and Docker.
